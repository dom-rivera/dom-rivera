## Featured work

### [Attachment Radar](https://github.com/dom-rivera/attachment-radar) · HR process automation
**Problem:** A recruiting team had no shared view of which candidates still owed signed offer documents, and follow-ups depended on memory.

**Solution:** Two Power Automate flows that announce each new offer in Microsoft Teams, send a reminder every two days and notify the team when the signed documents arrive.

**Design choice:** The mailbox is the only source of truth, so no candidate data is stored anywhere else and no extra data-retention review was needed.

### [People Analytics](https://github.com/dom-rivera/People-Analytics) · Python
**Approach:** Each analysis starts with a question an HR leader would ask and ends with a plain-language recommendation.

**Current study:** Employee attrition across 1,470 employees. The overall attrition rate is 16.1%, above typical turnover benchmarks. Statistical testing and logistic regression on the key drivers are in progress.

**Roadmap:** 15 more public HR datasets covering pay equity, performance, engagement and workforce planning.
